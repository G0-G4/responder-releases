# Responder

Responder — приложение для автоматической обработки отзывов на маркетплейсах: читает новые отзывы, генерирует и отправляет на них ответы по заданным вами правилам, работая в фоне на вашем компьютере.

Подробнее и живой пример генерации ответа — на [сайте проекта](https://g0-g4.github.io/responder-releases/).

## Возможности

- автоматический сбор новых отзывов (сейчас поддерживается Wildberries);
- гибкая генерация ответов — шаблоны под конкретную оценку/наличие комментария, с вариативностью, чтобы ответы не выглядели одинаково;
- фильтры — например, не отвечать автоматически на отзывы с низкой оценкой, оставляя их для ручной обработки;
- удобная консоль в браузере для настройки ботов, фильтров и генераторов ответов;
- иконка в системном трее — видно, что приложение работает, сколько отзывов обработано и есть ли ошибки.

## Установка и запуск

1. Скачайте архив последнего релиза для вашей ОС на странице [Releases](../../releases).
2. Распакуйте архив в удобную папку.
3. Запустите `server` (или `server.exe` на Windows).
4. Откроется иконка в трее — через неё можно открыть консоль управления в браузере.

Никакой отдельной установки не требуется — приложение работает как есть из распакованной папки.

## Активация

При первом запуске консоль покажет статус «Не активирована» и уникальный идентификатор вашего устройства (hwid). Отправьте его тому, кто выдал вам доступ, чтобы получить лицензионный ключ, и введите ключ в консоли на странице «Лицензия».

## Поддержка

Если что-то не работает — свяжитесь с тем, кто предоставил вам доступ к приложению.
